# Cosmic starfield background

`space.png` is an opaque background created for this project using the built-in imagegen tool.
It is loaded once during startup and released before the window closes. Drawing preserves
the image's aspect ratio, fills the window, and uses nearest-neighbor filtering for the pixel artwork.
If the image is missing, the application falls back to its dark gradient.

## Generation prompt

Use case: stylized-concept. Create one finished raster background asset for a small desktop arcade game collection, cosmic starfield theme. Wide landscape 16:9 composition, ideally 1920x1080 or higher. Cohesive polished pixel-art illustration with deliberate crisp stepped pixel clusters, restrained retro arcade aesthetic, not photorealistic, no blur. Deep midnight navy universe with indigo and muted violet nebula wisps, sparse tiny cool-white and pale-cyan stars, occasional small cross-shaped twinkles. Interesting cosmic depth and a few tasteful small distant celestial shapes near the outer edges; the central 75 percent must stay relatively dark and low-detail because wide game-selection cards and game boards overlay it. No large bright planet or star behind center, no huge circles, no characters, no spacecraft, no game icons, no text, no letters, no labels, no UI controls, no borders, no logo, no watermark. Keep brightness restrained, elegant, playful, quiet, suitable as a reusable full-screen game background. Edge-to-edge finished opaque image.
